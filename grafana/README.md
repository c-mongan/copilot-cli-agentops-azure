# Grafana dashboards

**Import this one:** [`agentops-copilot-cli.json`](agentops-copilot-cli.json).

It is the portable dashboard for Copilot CLI runs. It uses only the built-in Azure Monitor data source, needs no plugins, and contains no subscription, workspace or data source IDs. It imports unchanged into the Azure portal, Azure Managed Grafana and self-hosted Grafana. Import steps: [docs/grafana.md](../docs/grafana.md).

The other JSON files are kept for existing users and tests. You do not need them to get started.

| Files | Status | Use |
|---|---|---|
| `agentops-copilot-cli.json` | **Recommended** | One portable dashboard. Generated by `scripts/build-grafana-portable-dashboard.js`. |
| `dashboards/v2/*.json` (10 files) | Advanced | The V2 control-room pack. `agentops validate-azure --import-dashboards` and `provisioning/` use it. It expects the wider AgentOps table set. Tour: [docs/grafana-dashboard-tour-v2.md](../docs/grafana-dashboard-tour-v2.md). |
| Other `agentops-*.json` in this folder (14 files) | Legacy | The earlier dashboard pack, imported by `scripts/grafana-import-dashboard.sh`. Kept for compatibility; not maintained for new setups. |
| `kql/`, `provisioning/` | Supporting | Shared KQL and Grafana provisioning for the V2 pack. |
