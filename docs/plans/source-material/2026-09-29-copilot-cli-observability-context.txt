Yes. This has moved quite a bit recently, and the current docs are **much closer to the architecture you were describing earlier**.

### The important bit

**GitHub Copilot CLI natively emits OpenTelemetry now.** Its trace tree is basically:

```text
invoke_agent
├── chat                   # model call
├── execute_tool           # tool call
├── chat
├── execute_tool
└── ...

subagent: invoke_agent
├── chat
├── execute_tool
└── ...
```

Top-level agents **and subagents** get `invoke_agent` spans. GitHub records agent name/ID, model, token usage, durations, errors, tool names, tool execution duration, MCP connections, lines added/removed, and workflow duration. That means you can reconstruct **which agent called what, in what order, how long each thing took, whether it errored, and how many model/tool calls occurred** from native telemetry. :chatgpt-content-reference{index="0"}

Crucially, **prompts, responses and tool arguments are OFF by default**. You only get metadata unless you deliberately set `OTEL_INSTRUMENTATION_GENAI_CAPTURE_MESSAGE_CONTENT=true`. :chatgpt-content-reference{index="1"}

### Copilot CLI → Azure

The clean Microsoft-native architecture is:

```text
GitHub Copilot CLI
       │
       │ OTLP/HTTP
       ▼
OpenTelemetry Collector
       │
       ▼
Azure Monitor / Application Insights
       │
       ├── Log Analytics + KQL
       ├── Application Insights Agent views
       └── Azure Monitor Grafana dashboards
```

Microsoft actually has an end-to-end **“Monitor AI coding agents with Grafana”** guide covering GitHub Copilot alongside Codex, Claude Code, Gemini CLI, etc. The supplied Copilot dashboard includes sessions, tokens, model usage, tool calls, response latency and TTFT. :chatgpt-content-reference{index="2"}

Basic CLI configuration is essentially:

```bash
export COPILOT_OTEL_ENABLED=true
export OTEL_EXPORTER_OTLP_ENDPOINT=http://localhost:4318
export OTEL_EXPORTER_OTLP_PROTOCOL=http/protobuf
export OTEL_SERVICE_NAME=github-copilot
```

Then point the Collector at Azure Monitor/Application Insights. GitHub also supports OTLP auth headers and enterprise-wide configuration. :chatgpt-content-reference{index="3"}

### Enterprise deployment is especially relevant

As of **July 8, 2026**, GitHub added enterprise-managed OTel configuration for **both VS Code and Copilot CLI**. Admins can centrally enforce endpoint, protocol, service name, resource attributes, authentication headers and whether content capture is allowed. :chatgpt-content-reference{index="4"}

Example managed configuration:

```json
{
  "telemetry": {
    "enabled": true,
    "endpoint": "https://our-otel-collector",
    "protocol": "http/protobuf",
    "captureContent": false,
    "lockCaptureContent": true,
    "serviceName": "github-copilot",
    "resourceAttributes": {
      "deployment.environment": "production"
    }
  }
}
```

That `telemetry` block is officially supported for **Copilot CLI + VS Code**. :chatgpt-content-reference{index="5"}

### Hooks still matter

Native OTel handles most observability. Hooks then become the extension mechanism for things GitHub doesn't emit natively.

Copilot has:

`sessionStart`, `sessionEnd`, `userPromptSubmitted`, `preToolUse`, `postToolUse`, `agentStop`, `subagentStop`, `errorOccurred`.

So you can enrich native traces with your own things like:

```text
ADO build ID
repository
team
experiment ID
agent architecture version
evaluation ID
task category
failure classification
user feedback
```

and send those into the same Azure pipeline. :chatgpt-content-reference{index="6"}

### Preview status

There are a few similarly named things:

- **Copilot CLI OTel instrumentation:** documented supported functionality; current GitHub docs do **not** label it preview. :chatgpt-content-reference{index="7"}
- **Enterprise-managed Copilot OTel export:** shipped July 8, 2026; not described as preview in GitHub's announcement. :chatgpt-content-reference{index="8"}
- **Azure Monitor OTel Collector ingestion:** Microsoft's latest overview says the Collector path is **GA**; the Azure Monitor Agent and AKS ingestion paths remain preview. Some older pages still contain “Preview” wording. :chatgpt-content-reference{index="9"}
- **Azure Copilot Observability Agent (preview):** separate product. That's an AI assistant for investigating Azure Monitor data, **not** what collects Copilot CLI telemetry. :chatgpt-content-reference{index="10"}
