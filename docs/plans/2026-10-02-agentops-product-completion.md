## Global constraints

- Metadata only by default; no secrets, prompts, code or raw tool payloads in derived product contracts.
- Preserve exact, logical, inferred, ambiguous, unsupported and unknown evidence. Source presence and expected stimulus counts do not prove global completeness.
- Freeze bounded metadata-only inventory before launch; changed or late manifests cannot establish pre-run configuration.
- Unknown measurements stay unknown; process exit, task success, API acceptance and typed cloud readback remain separate.
- Treatment is intentional change; model/runtime/tool/MCP/task/dataset/grader drift is a comparison failure unless explicitly the tested treatment.
- Proposals never apply or approve refactors. Existing historical experiment decisions remain historical.
- No automatic global hooks, model calls, hosted writes, broad template application or paid service activation.
- Workers own disjoint source paths. Focused checks first; heavy integrated checks run serially. Parent owns integration, review and final evidence.

2. Review diff against the acceptance contract; repair meaningful findings with the owning worker.
3. Run integrated CLI/SDK/fixtures, static/assets/schema/product/dashboard/coverage/install checks after side-effect inspection. Run serially through verified storage routing.
4. Exercise actual current-source Runs/replay/Architecture/Compare plus new diagnostic/outcome flow in an isolated browser at desktop/mobile. Capture console/page errors, canary absence, keyboard navigation and axe results.
5. Run generated held-out and diagnostic fixture grading, preserve failed candidates, and compare qualified outcome rows to the intended schema/query contract. Live model trials and human studies remain separately labelled until executed.
6. Refresh Graphify after integrated source changes; obtain an independent whole-change review and scoped re-review after repairs.
7. Read back final status/diff. Preserve unrelated changes. Report implemented, locally verified, live/cloud verified, prepared and blocked items separately.
